⚠️ **Второй вопрос к кабинету:** можно ли держать залог и выбрать валюту прибыли в

🔑 И побочно: существование `PF_USDCUSD` означает, что **сам базис USDC/USD на

# Приложение 2. Секундный сбор Kraken поднят; вопросы 1 и 2 по документации

## Сбор Kraken (18.09.2026)

Служба `kr-book` на micro, рядом с захватом Бинанса. Публичный WebSocket
`wss://futures.kraken.com/ws/v1`, фид `ticker`, три контракта.

| | |
|---|---|
| темп | **8.4 сообщения в секунду** на три контракта (BTC 3.8, ETH 2.5, SOL 2.1) |
| размер | 644 байта на строку → **~470 МБ в сутки** сырого текста, столько же, сколько у Бинанса |
| поля | `time` (биржевая отметка!), `product_id`, `bid`, `ask`, `bid_size`, `ask_size`, плюс фондирование и `premium` |
| диск micro | 34 ГБ свободно; два захвата дают ~0.94 ГБ/сут сырых, ночью жмутся в десять раз |

🔑 **Задержка до площадки измерена сразу, потому что Kraken присылает свою
отметку времени:** наша минус биржевая — **в среднем 220 мс, максимум 1059 мс**
(часы micro синхронизированы по NTP). У Бинанса `bookTicker` своей отметки не
имеет, и такой замер там невозможен в принципе.

Устройство повторяет `bnb-collect.sh` после вчерашней правки — FIFO вместо
`sleep` в конвейере, `--ping-timeout`, обязательный `-E`, выбор файла по каждому
сообщению. Чистка и сторож темпа переиспользованы через окружение
(`DIR`, `STATE`, `LABEL`, `SERVICE`), две строки в кроне: упаковка 04:37, сторож
каждые 15 минут. Сторож проверен на новом каталоге.

## Вопрос 1: какой тариф на нашем счёте — по документации

| источник | что говорит |
|---|---|
| **страница Kraken «Fees for Derivatives trading for EEA clients»** | тариф по 30-дневному обороту: при $0+ **мейкер 0.0200%, тейкер 0.0500%**; отрицательный мейкер с $250 млн. **Разделения на «consumer» и «professional» на странице НЕТ** — расписание одно для всех клиентов ЕЭЗ |
| **общая страница «Fees for Derivatives trading»** | то же самое: только сетка мейкер-тейкер от 0.02/0.05, ни слова про 0.25% |
| **публичный API** | наши три контракта ссылаются на расписание **«MTF Linear Rebate Fees»** с нижней ступенью 0.0200 / 0.0500 |
| сторонние обзоры | встречается «0.25% при открытии и закрытии» — это и есть то самое «Consumer MTF Linear Fees» из API |

🔑 **Вывод: тревога из П0.3 documentation-ю не подтверждается.** Kraken для
клиентов ЕЭЗ публикует ровно 2 б.п. мейкера, и расписание наших контрактов в API
то же. Ни одна страница самого Kraken не приписывает деривативам 0.25% — эта
цифра нашлась только в стороннем обзоре.

⚠️ **Но документация не может сказать, какое расписание назначено НАШЕМУ счёту.**
Это по-прежнему закрывается одним запросом с ключом (у нас он есть — на Kraken
Futures торгует S5), и я его не делал: ключ боевой, а вопрос не срочный.

## Вопрос 2: USDC как залог и валюта прибыли — ⚠️ документация противоречит сама себе

| источник | что говорит |
|---|---|
| **«Derivatives Collateral Currencies»** | стейблкоины принимаются залогом: **USDC с haircut 0.50% и нулевой комиссией конвертации**, рядом USDT, EURC, USDG, XAUT |
| **«Linear Multi-Collateral … Specifications» (общая)** | «Linear-инструменты рассчитываются в USD по умолчанию **или в выбранной вами валюте прибыли**» |
| ⚠️ **та же спецификация ДЛЯ КЛИЕНТОВ ЕЭЗ** | залог описан у́же: «USD, с полными опциями обеспечения в **EUR и GBP** после haircut». **USDC там не назван** |

То есть общая документация говорит «USDC можно и залогом, и валютой прибыли», а
страница для нашей юрисдикции перечисляет только фиат. Расхождение ровно в том
месте, от которого зависит ответ: **есть базис между спотом в USDC и хеджем в USD
или нет.**

🔑 **Оба вопроса упираются в одно и то же: один запрос к Kraken с ключом.**
`GET /derivatives/api/v3/accounts` покажет кошелёк мульти-коллатерала со списком
валют, а тарифная ветка — назначенное расписание. Это чтение, ордеров не
касается; у нас уже есть боевой ключ S5 и команда `--s5-kraken-check`, которая по
описанию read-only. **Делать или нет — ваше слово: ключ торговый.**

⚠️ Пока не сделано, П2.1 (арифметика хеджа) считается в двух вариантах — с
базисом и без, — и половина работы выбрасывается.
