## 3. Что попробовали и чем кончилось

| Гипотеза | Результат | Где |
|---|---|---|
| Композит из 5 источников | отвергнут: смешивал направление с фазой цикла | 01 v2 §1 |
| Три ортогональные оси D/T/S | оси ортогональны (`corr(D,T)=0.074`), экономику это не улучшило | 20 §3 |
| Ось S, `dd_speed` | отвергнут: храповик, 515 дней в CRASH (21.5% истории) | 18, A1/A2 |
| Состояние CRASH | отвергнут: CAGR 26.9% против 32.7% без него при **идентичной** просадке | 18, A4 |
| Дневной таймфрейм для каскада ликвидаций | не годится: паника распознаётся на 53% движения | 18, A7 |
| Volatility targeting | отвергнут: 67% дней на потолке, min экспозиция 0.29, защита/цена 0.79 | 19 v2 |
| `stress_level` как множитель | выключен постоянно: диапазон [0.5, 1.0] выходит ещё меньше | 01 v4 §2.4 |
| CUSUM | отвергнут: ratio 0.44, избыток над контролем незначим | 20 |
| Композит D+T против SMA200 | **отвергнут**: −25.6% было свойством окна; на 2015–2026 стало −57.9% | 20 §1 |
| Ансамбль голосованием | отвергнут: лучше SMA200 по ratio на 0/6 рынков | 20 §3 |
| Контроль с матчингом экспозиции как защита композита | аргумент отозван: не воспроизвёлся на кросс-рынке | 20 §1.3 |
| Funding как определитель режима | **не проверяется**: наблюдений столько же, кросс-рынок невозможен | 21 v2 §3 |
| **Гейт наклона SMA** | **отвергнут**: задача A — 1/6 (нужно ≥4); задача B — 0/2 | 21 v2 §4 |

### Итог направления

`close > SMA200 → BULL, иначе BEAR`. Ноль параметров.

Выбран **не как доказанно лучший, а как самый дешёвый среди статистически неразличимых**: дефлированные Sharpe при N=9 у всех около нуля (SMA200 −0.044, композит +0.017), перестановочный тест значимости не дал никому.

### Главные методические выводы

1. **Тривиальный бенчмарк прогоняется первым.** SMA200 — полчаса работы — прогнан последним, после четырёх версий детектора.
2. **Проверка на расширенном окне обязательна до любых выводов.** Расхождение −25.6% / −57.9% на одном активе решило исход.
3. **Добавление источников данных не добавляет наблюдений.** Режимных эпизодов около десяти, сколько признаков ни навешивай.
4. **Дефект, выводимый из определения формулы, не требует бэктеста.** Три случая: храповик `dd_speed`, отсутствие выхода у vol targeting, реактивность `σ_t` в GARCH.
5. **Медиана длительности состояния = порог гистерезиса** → стабилизирует гистерезис, а не сигнал.
6. **Провалившийся тест может вскрыть вопрос уровнем выше.** Задача B гейта показала не «гейт плохо отделяет условия», а «S3 убыточна в любых условиях» (§4).

## 4. Документы, требующие обновления

Не имеют новых версий, но содержат утверждения, ставшие неверными. Опаснее архивных: те помечены номером версии, эти выглядят актуальными.

### 00-obzor-arhitektura.md

Описывает архитектуру с композитным детектором и состояниями `RANGE` / `TRANSITION` / `CRASH`. Ничего из этого не существует.

Нужно: заменить описание детектора на SMA200, убрать удалённые состояния, обновить схему потока данных.

### 02-strategii.md

Матрица активации опирается на несуществующие состояния.

Нужно:
- S1 — гейт меняется на `state ≠ BULL`;
- **S3 — статус «под вопросом»** (не «приостановлена»). Измерение: −34% годовых на BTC и −80% на ETH, убыточна **в обоих режимах**. До проверки §5 doc 21 v2 считать её живой стратегией нельзя;
- S6 — проверить отображение `ACCUMULATION + не BULL`;
- S2/S9, S4, S5, S7 — без изменений.

### 03-risk-management.md

Проверить, нет ли ссылок на `CRASH` как на триггер экстренного снижения экспозиции.

### 09-istochniki-dannyh-v4.md

Проверить, не значатся ли on-chain и макро **входами детектора**. Они модификаторы и на состояние не влияют.
