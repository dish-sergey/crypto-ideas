# 215. Аск по старому лоту: продавать раньше или ближе к рынку (сетка 26–27.10.2026)

Итог: правила, которые продают купленный лот раньше или ближе к рынку, почти везде проигрывают живой настройке. Единственное исключение — BTC L3 с подтягиванием по возрасту до 2/3 отступа: +6…+8% за месяц, 5 недель из 6.

## 0. Что проверялось

Вопрос: бот купил лот и «таскает» его, продавая в случайном месте. Проверены три семейства правил для аска по старому лоту, каждое на шести клетках (BTC, ETH, SOL × один уровень L1 / три уровня L3).

- **Подтягивание по возрасту (lvdNfF).** Лот лежит дольше N мин — за 2 мин аск подходит к опоре до доли F своего отступа (f33 — до трети, f67 — до двух третей).
- **Аск первым (lvfaN, lvfj15).** Через N мин аск встаёт на шаг перед лучшим чужим аском (lvfj — на его цене), но не ближе опоры + 1 б.п.
- **Рост над ценой покупки (lvrX).** За каждые X б.п. роста опоры над ценой покупки аск на 1 б.п. ближе, не ближе «первым». Опора роста: самый старый лот (без буквы), средняя цена запаса (a), последний лот (l). Сдвиг не копится: на откате аск возвращается.

**Стенд.** Боевой котировщик на записанной книге, модель исполнения по очереди, лот ×5, эффекты затыка площадки, включая запаздывание замены (`lag`). Деньги — с переоценкой запаса (захват + снос + бета). База (lvx5) — живые настройки каждого бота на 27.10.

**Флаги стенда.** `revx.sim.ask-decay-after/-min/-floor`; `revx.sim.ask-first-after`, `-gap-steps`;
`revx.sim.ask-rise-bp`, `revx.sim.ask-rise-ref=oldest|avg|last` (коммиты 4f9815f, 384335e; jar `tools136–138`).
Сетки `C:/revx-xrp/hdecay.sh`, `hfirst.sh`, `hrise3.sh`; Carry — `cx/carry.csv`, качество — `fillq2-hg.csv` /
`fillq2-ho.csv`. Живым не включено.

**Окна.** Месяц 15.09–18.10 разбит на недели w1–w5 (w5 короче); w6 — отдельный прогон 18–25.10.

**Колонки.** «месяц» — изменение итога за 15.09–18.10 в % к базе; w1…w6 — разность в $ к базе; «побед» — недель из шести, где вариант лучше; «сделок» — изменение числа сделок; «маркаут 5 мин» — качество сделки (захват плюс ход за 5 мин), б.п., база → вариант.

Оговорка: стенд детерминирован, но одно смещённое исполнение уводит траекторию; разница в несколько процентов за месяц сравнима с шумом (плацебо календаря давало ±6…12% итога).
