## 3. Что попробовали и чем кончилось

### 3.1 Детекторное направление

| Гипотеза | Результат |
|---|---|
| Композит из 5 источников | отвергнут: смешивал направление с фазой цикла |
| Три ортогональные оси D/T/S | оси ортогональны (`corr` = 0.074), экономику не улучшило |
| Ось S с `dd_speed` | храповик, 515 дней в CRASH (21.5%) |
| Состояние CRASH | CAGR 26.9% против 32.7% при идентичном MaxDD |
| Volatility targeting | 67% на потолке, защита/цена 0.79 |
| CUSUM, ансамбль, гейт наклона | все хуже однострочника |
| **Итог** | `close > SMA200 → BULL, иначе BEAR`, ноль параметров |

### 3.2 Стратегии

| Стратегия | Результат |
|---|---|
| S1 funding-арбитраж | запас над альтернативой +2.3 п.п. при требуемых 4; активна 17% времени |
| S3 mean reversion | минус даже при нулевых издержках (−46% BTC, −61% ETH) |
| S4 стейблкоин-доходность | **убита регулированием** (MiCA ст. 50) |
| **S12 кросс-секционный carry** | **премия арбитрирована к −34% в 2023–26** на PIT-вселенной |
| Межбиржевой funding-спред | ноль инструментов сочетают спред >20% с оборотом >$2M |

### 3.3 Методические выводы

1. **Тривиальный бенчмарк прогоняется первым.**
2. **Проверка на расширенном окне обязательна до выводов.**
3. **Добавление источников данных не добавляет наблюдений.**
4. **Дефект, выводимый из определения формулы, не требует бэктеста.**
5. **Медиана длительности состояния = порог гистерезиса** → работу делает гистерезис.
6. **Провалившийся тест может вскрыть вопрос уровнем выше.**
7. **Одна метрика может не годиться для одной задачи и годиться для другой.**
8. **Проверять первичные данные, а не описания данных** (интервал funding Kraken: 1ч, а не 4ч из документации вендора).
9. **Метрика ёмкости после фильтра описывает не то, что отбирает стратегия.**
10. **Фильтр ликвидности зависит от размера капитала**, не абсолютен.
11. **Винзоризация ≠ модель ликвидации.** Обрезание до порога и обнуление позиции — разные операции.
12. **Если знак результата меняется от способа обработки выбросов — оценке нельзя доверять.**
13. **Завышает не только выживаемость, но и выбор периода** (S12: PIT ≈ наивная, но подпериоды различаются радикально).
14. **Серия промахов ожидания в благоприятную сторону — признак неполной модели**, а не найденного преимущества.

### 3.4 Закономерность (новое в v4)

**Умерли все стратегии сбора наблюдаемой премии** — S1, S12, S4. **Выжили те, что стоят на вынужденном поведении контрагента** (S5, S7) **и на медленной диффузии информации** (S2/S9, SMA200).

Подробно — `t03 v3` §5. Практическое правило: **ищите не то, чего не видно, а то, что неудобно.** Премия за дискомфорт переживает известность; премия за наблюдаемую ставку сжимается.
