# Чеклист: первые две недели (по вечерам)

> Как пользоваться: делай по одному-двум пунктам за вечер, ставь `[x]` вместо `[ ]`. Пункты идут в удобном порядке, но внутри блока — сверху вниз. Рядом с каждым — примерная оценка времени. «⏱️кор» = 10–20 мин (короткий вечер), «⏱️сред» = 30–60 мин, «⏱️длин» = 1.5–3 ч (когда есть время посидеть).

## Неделя 1 — деньги начинают работать + инфраструктура

### Блок A. Первая прибыль (идея №1) — начни с этого

- [ ] ⏱️кор — Revolut: переложить рабочий капитал в сберегательный счёт EUR или PLN (earn на фиат). **С этого момента деньги уже приносят процент.**
- [ ] ⏱️кор — Записать в отдельный файл/заметку: стартовую сумму и дату. Это точка отсчёта P&L (нужна для контрольной точки через 3 мес).

### Блок B. Kraken — подготовка (без ввода денег)

- [ ] ⏱️кор — Проверить, пройдена ли appropriateness-анкета для Futures (если нет — пройти).
- [ ] ⏱️кор — Ввести налоговый номер (PESEL/NIP), если Kraken запросит для деривативов.
- [ ] ⏱️сред — Создать API-ключ: права **только чтение + торговля**, БЕЗ права вывода. Приватную часть сохранить в надёжном месте (не в облаке/не в гит).
- [ ] ⏱️сред — Выписать из `instruments` (Kraken Futures API) для `PF_XBTUSD` и `PF_ETHUSD`: минимальный размер ордера, шаг лота (`tickSize`, `contractSize`), и свои актуальные тарифы maker/taker. Это нужно, чтобы понять, реализуема ли дельта-нейтральность S1-lite на нашем малом номинале (записка 10 §6.4).

### Блок C. Revolut X — доступ для бота

- [ ] ⏱️сред — Создать API-ключ Revolut X (Ed25519), приватный ключ сохранить безопасно.
- [ ] ⏱️кор — Посмотреть в приложении/на сайте типичный спред BTC/EUR в спокойное время суток, записать значение (проверка, что ликвидность годная для наших ботов).

### Блок D. Хостинг (бесплатный сервер)

- [ ] ⏱️сред — Oracle Cloud: регистрация. **Домашний регион выбрать в ЕС** (Frankfurt / Amsterdam и т.п.) — потом не меняется. Нужна карта для верификации.
- [ ] ⏱️сред — Создать Always Free инстанс (ARM Ampere, EU-регион).
- [ ] ⏱️сред — Настроить SSH-доступ к серверу.
- [ ] ⏱️кор — Поставить на сервер Python + git + базовые пакеты.
- [ ] ⏱️кор — Прописать IP-whitelist на Kraken API-ключе → фиксированный IP сервера.

## Правила по ходу (чтобы не сбиться)

- **Одно изменение за раз.** Не запускать два новых модуля в один вечер вслепую — сложнее понять, что сломалось (док. 04 §6).
- **Пока без реальных денег в ботах.** Всё в неделях 1–2 — это инфраструктура и бумажный режим. Реальный капитал в боте появляется только в идее №2 позже (неделя 5 плана), и это просто переключение собственного BTC без плеча.
- **Деньги живут на Revolut X.** Kraken пополняем только когда дойдём до запуска S1-lite. «Одна биржа с деньгами, две с доступом».
- **Коллекторы не останавливать.** Как только заработали на сервере — пусть пишут всегда.

## Что дальше (недели 3–6, ориентир — не делать сейчас)

Идея №2 в бумаге → идея №2 в live (реальный капитал) → S1-lite (funding на Kraken) в бумаге → S1-lite live-micro. Подробности — план 11 v3. Вернёмся к этому, когда чеклист выше будет с галочками.
