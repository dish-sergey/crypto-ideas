# Рейтинг бирж для старта: Польша, ВНЖ, июль 2026

> Статус: решение + рейтинг. Контекст: старт на Revolut X (решено), Binance выбыла (без MiCA-лицензии, сервисы в ЕС ограничены). Оператор — резидент Польши по ВНЖ (karta pobytu), паспорт не ЕС → KYC сложнее обычного. Капитал ≤$3k, план — док. 11 v3.

## 1. Три факта, которые меняют картину для ЕС (важнее самого рейтинга)

1. **USDT на регулируемых площадках ЕС недоступен.** После вступления MiCA биржи делистнули пары с USDT для клиентов ЕЭЗ (не соответствует требованиям к стейблкоинам). Рабочие котировочные валюты на EU-платформах — **EUR и USDC**. Все правила пакета, где написано «USDT», в ЕС читаются как «USDC/EUR».
2. **Доходность на стейблы на биржах ЕС фактически закрыта.** MiCA запрещает CASP и эмитентам начислять проценты на e-money-токены (USDC и аналоги) — поэтому «earn на стейблы» на лицензированных площадках либо отсутствует, либо сведён к нулю. Следствие для идеи №1 (парковка, док. 11): роль «пола доходности» переходит к **процентам на фиат PLN/EUR** (например, сберегательные счета в том же Revolut) и/или, позже и осторожно, к самостоятельному DeFi-лендингу USDC на L2 (вне CASP, лично — не запрещено; газ на mainnet при наших суммах съедает смысл).
3. **Санкционный нюанс для паспортов РФ/РБ:** запрет на криптосервисы для граждан РФ имеет исключение для обладателей ВНЖ/ПМЖ ЕС — оно продолжает действовать (20-й пакет от мая 2026 бьёт по CASP, зарегистрированным в России, а не по резидентам ЕС). Но биржи применяют правило с разной строгостью: при онбординге сразу загружать документ о резидентстве (karta pobytu + подтверждение адреса). Если конкретная площадка отклонила — не обходить через VPN (прямой путь к заморозке), а идти к следующей по рейтингу.

## 2. KYC с картой побыту: что реально понадобится

Основной ID почти везде — **загранпаспорт** (карта побыту как ID принимается редко, но она и не нужна как ID). Подтверждение адреса: банковская выписка с польским адресом (выписка Revolut подходит на большинстве площадок), счёт за коммуналку, официальные письма. Подтверждение резидентства для санкционного исключения (если паспорт РФ/РБ): karta pobytu. Налоговое резидентство в анкетах: Польша (PIT-38, 19% на крипто-фиат; крипта-крипта не облагается — но с 2026 биржи начинают отчитываться о клиентах, вести учёт сделок с первого дня).

## 4. Итоговая конфигурация (обновление плана док. 11)

- **Сейчас:** Revolut X — идеи №2 и №4 на парах BTC/EUR (или BTC/USDC); парковка №1 = сберегательный счёт PLN/EUR в Revolut (те же единицы % годовых, что давали стейблы, но регулируемо и без крипториска депега).
- **Параллельно (без депозита):** пройти KYC на Kraken как второй площадке — проверить боем доступность деривативов для розничного резидента Польши с ВНЖ. Если перпы доступны → S1-lite (идея №3) строится там; если нет → S1-lite ждёт, ядро плана не страдает.
- **Отступление §1.1 дока 11 (одна биржа) смягчается до «одна биржа с деньгами»:** KYC на второй — бесплатен и снимает риск единой точки отказа при заморозке/сбое первой (урок zondacrypto).
- Кто-то из пары OKX EU / Bybit EU добавит перпы для розницы раньше Kraken — следить раз в месяц, это дешёвая проверка.
