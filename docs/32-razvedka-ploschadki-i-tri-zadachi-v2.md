**Назначение:** результаты разведки Kraken, следствия для пула стратегий, задания для исполнителя (Claude Code).
**Что изменилось в v2:** §1 закрыт — перпетуалы доступны, API истории проверен; обнаружены два расхождения с нашими допущениями (интервал funding, глубина истории сделок); задачи пересмотрены.
**Зависимости:** `31-mica-i-peresmotr-yadra-v2.md`, `24-…md`, `27-…md`, `16-kross-sekcionnye-strategii.md`.

**Оговорка.** Регуляторные сведения собраны по открытым источникам. Я не юрист; условия конкретного счёта проверяются в пользовательском соглашении и у поддержки площадки.

## 1. Результаты разведки

### 1.1 Перпетуалы доступны

Клиенты в ЕЭЗ могут торговать бессрочными и срочными криптоконтрактами; продукт соответствует MiFID II и предоставляется через приобретённую инвестиционную фирму с лицензией MiFID (кипрское юрлицо).

Доступно **более 150 рынков бессрочных фьючерсов** (по другой оценке — 170+ контрактов).

**Следствие:** возражение о числе инструментов снято. S12 (кросс-секционный carry) реализуема по этому критерию.

### 1.2 Разделение юрлиц — важно для риска

| Функция | Юрлицо | Режим |
|---|---|---|
| Хранение цифровых активов (спот) | Payward Europe Solutions Limited | кастодиан по MiCA |
| Маржинальное кредитование и деривативы | PEDSL-CY | брокер по MiFID |

Каждое юрлицо действует строго в рамках собственных разрешений; совместная услуга и перекрёстная ответственность между ними не подразумеваются.

**Практическое следствие:** спот и деривативы — два разных контрагента с раздельной ответственностью. Проблема у одного не покрывается другим. В `03-risk-management-v2.md` §5 контрагентский риск считался по площадке целиком — надо считать по каждому юрлицу отдельно.

### 1.3 Плечо: регуляторный потолок совпадает с нашим

ESMA выпустила публичное заявление, что бессрочные фьючерсы, вероятно, попадают в категорию CFD. Провайдеры в ЕС сейчас дают до 10x; при классификации как CFD потолок станет **2x**. На середину 2026 авторизованные в ЕЭЗ площадки с розничными перпами ограничены диапазоном 3x–10x с обязательным тестом на понимание продукта.

**Нам это не мешает.** Наш собственный лимит уже 2x — значение 3x запрещено после обнаружения внутридневного роста +36.2% против уровня ликвидации при 3x (`27` §2). Худший регуляторный сценарий совпадает с тем, что мы себе назначили по результатам измерения.

Побочный плюс: при классификации как CFD добавляется защита от отрицательного баланса, что ограничивает хвостовой риск.

### 1.4 Перпетуалы — MiFID, не MiCA

Бессрочные фьючерсы регулируются MiFID II; регуляторы ЕС считают крипто-перпы деривативами, и лицензии MiCA недостаточно для их предложения в ЕЭЗ.

**Следствие:** запрет процентов по стейблкоинам (MiCA, статья 50) к funding-доходу от перпетуалов отношения не имеет — разные режимы. **S12 под статью 50 не подпадает.**

### 1.5 Доступность данных через API

| Данные | Доступность | Примечание |
|---|---|---|
| Историческая ставка funding | публичный эндпоинт `/derivatives/api/v3/historical-funding-rates` | без авторизации |
| Mark price | есть | см. §2.2 |
| Открытый интерес | есть | для `leverage_warning` |
| OHLCV | есть | — |
| **История сделок** | **только 7 дней** | 100 последних сделок до указанного времени; см. §2.3 |

## 2. Три следствия, меняющие реализацию

### 2.1 Интервал funding — четыре часа, а не восемь

**Все наши пороги и формулы считались от восьмичасового периода** (Binance). У Kraken интервал — четыре часа.

| Величина | Было (8ч) | Стало (4ч) |
|---|---|---|
| Аннуализация | `f × 3 × 365` | `f × 6 × 365` |
| Порог активации S1/S12 | 0.010%/8ч | **0.005%/4ч** |
| Порог `funding_persist` в `leverage_warning` | 0.05%/8ч | **0.025%/4ч** |

**Скопировать числа нельзя — надо конвертировать.** Это не изменение критерия, а приведение к другой единице измерения; экономический смысл порога сохраняется.

Проверить все места, где фигурирует «8ч»: `02-strategii.md` (S1), `01-detektor-rezhima-v5.md` §2 (`leverage_warning`), `23-…md` §4.3, `27-…md` §6.2, `31-…-v2.md`.

### 2.2 Mark price доступен — модель S1/S12 чинится

В `26-…md` §3.1 записано: аппроксимация ценой закрытия вместо mark price занижает хвост **систематически**, поскольку mark сглажен и расходится с close именно в стрессе.

Теперь mark доступен. При любом пересчёте S1 или построении S12 использовать его, а не close. Оговорку из `s1_backtest_v2.md` можно снять.

### 2.3 История сделок 7 дней — S7 заблокирована

Внутридневной контур S7 требует ленты сделок и стакана на историческом периоде для разметки каскадов по часам (`29-…md` §3).

**Семи дней недостаточно.** Варианты:

| Вариант | Оценка |
|---|---|
| Платный источник (CoinAPI, Amberdata и аналоги) | покрытие funding с начала 2021 у большинства бирж; стоимость проверить |
| Собственный forward-сбор | начать писать ленту сейчас, тест возможен через год-полтора |
| Отказаться от тиков, работать на 1-минутных OHLCV | грубее, но может хватить для разметки каскадов |

Третий вариант стоит оценить первым: минутные свечи обычно доступны исторически, а для распознавания каскада минутного разрешения может быть достаточно.

**S7 остаётся отложенной**, но блокер теперь конкретный и с оценёнными обходами.

## 4. Задача A: конвертация единиц и пересчёт

**Приоритет высший — блокирует остальное.**

1. Конвертировать все пороги с 8ч на 4ч по §2.1. Записать в конфиг.
2. Пересчитать `leverage_warning` на данных Kraken (интервал 4ч) — ряд изменится.
3. Пересчитать бенчмарк: заменить ставку кэша 8% и 5% на фактическую доступную в евро по периодам (значение из §3.2).
4. Пересчитать решение по S1 (`27` §6.4) на новой базе и с mark price.

**Правила:** пересчёт один раз; **критерий 4 п.п. не меняется** — меняется база и единица измерения, не планка. Запись в журнал с пометкой «пересчёт базы и единиц, не новая гипотеза».

Результат может изменить решение по S1. Это допустимо: меняется вход, а не правило.

## 5. Задача B: вселенная перпетуалов Kraken

§1.1 снял вопрос о числе инструментов. Теперь — о глубине истории.

### 5.1 Что выяснить

| Вопрос | Как |
|---|---|
| Сколько инструментов торгуется сейчас, список | API инструментов |
| Есть ли история листингов и делистингов | архивы объявлений; наличие данных по неактивным символам |
| Глубина истории funding по инструменту | запросить по нескольким парам, зафиксировать самую раннюю дату |
| Доступна ли история funding по делистнутым парам | пробный запрос по известным делистнутым |
| Глубина истории OI | то же |

### 5.2 Критерий разблокировки

Вселенная перпетуалов считается пригодной для S12, если:

- восстановим состав инструментов на исторические даты (хотя бы помесячно);
- funding и OHLCV доступны по инструментам, **включая ушедшие**;
- глубина не менее 3 лет.

**Если делистнутые инструменты недоступны** — зафиксировать смещение выживаемости как ограничение и измерить его размер тем же способом, что для спота (`17` §3.3): прогон на наивной вселенной против корректной, разница в CAGR.

### 5.3 Почему это приоритет

S1 умерла не из-за механизма, а из-за редкости условий: премия доступна 17% времени, но даёт около 18.5% годовых в активные периоды (`30` §2).

S12 смотрит на 150+ инструментов сразу: пока funding низкий на BTC, он может быть высоким на других. Принцип `IR ≈ IC·√N` (`t10`) — расширять число ставок, а не частоту наблюдений.

Плюс §1.4: S12 не подпадает под запрет статьи 50.

## 6. Задача C: календари вестинга

Без изменений относительно v1. Данные полезны независимо от S5: `16-…md` §7.3 требует исключать из лонг-портфеля монеты с крупным разлоком в ближайшие 14 дней.

**Обязательное требование:** календарь point-in-time. Расписания вестинга пересматриваются; использовать сегодняшнее расписание для событий 2022 года — тот же look-ahead, что наивная вселенная.

**Event study не запускать** до завершения задач A и B — приоритет у S12.
