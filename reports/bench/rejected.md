# Реестр отвергнутого (док. 15 v4 §10)

Чтобы через полгода не начать заново уже закрытое. Возврат требует нового измерения, опровергающего основание, а не аргумента «попробуем иначе».

| Конструкция | Основание отказа | Что могло бы вернуть |
|---|---|---|
| Ось `S` с `dd_speed` | doc 18 A1/A2: храповик по построению, серии до 41 дня | ничего: дефект из определения формулы |
| Состояние `CRASH` | doc 18 A4: CAGR 26.9% против 32.7% при идентичном MaxDD | измерение выигрыша на другом рынке/таймфрейме |
| `baseline_voltarget` | doc 19: 67% на потолке, min экспозиция 0.29, защита/цена 0.79 | версия с плечом либо мультиактивный портфель |
| Множитель `stress_level` | doc 01 v4 §2.4: диапазон [0.5, 1.0] выходит ещё меньше | новое измерение под другую задачу (защита моментума, doc 17 §7) |
