# Переносимость funding Kraken ↔ Binance — решающий тест S12 (doc 34 §4)

**Вопрос (предрегистрация):** сохраняется ли кросс-секционное *ранжирование* инструментов по
funding между Kraken и Binance? Если да — S12 можно исследовать на 7-летней истории Binance,
торговать на Kraken. Если нет — бэктест на Binance измеряет не ту величину, что мы заработаем.

Проверено вживую 2026-08-08 на годе перекрытия. Код: `scratchpad/FundingTransfer.java`.

## Данные

| | |
|---|---|
| Kraken торгуемых перпов `PF_*USD` | 274 |
| Binance `PERPETUAL/USDT/TRADING` | 526 |
| **Пересечение (по базовому активу)** | **235 инструментов** |
| Окно перекрытия | 2025-08-06 … 2026-08-08 (**368 дней**) |
| Единицы | Kraken `relativeFundingRate`×24×365, Binance `fundingRate`×3×365 (годовые) |

Ранжирование инвариантно к множителю аннуализации, поэтому вывод **не** артефакт единиц —
он про порядок инструментов, а не про уровень.

## Результат

### Ежедневный срез (первичная метрика §4.2)

| Метрика | Значение |
|---|---|
| Средняя дневная Spearman `rho` | **0.163** (std 0.094) |
| **Доля дней `rho` < 0.5** | **100%** (368/368) |
| Доля дней `rho` < 0.8 | 100% |
| Совпадение верхнего дециля | 0.144 (случайность ≈ 0.10) |
| Уровневая Pearson `r` (пул) | 0.217 (n=84 874 инстр.-дней) |
| Ликвидные топ-10: средняя дневная `rho` | 0.227 |

### Годовое среднее — устойчивый карри (проверка без дневного шума)

Для S12 важнее не дневной срез, а сглаженный карри-сигнал. Усреднил funding по каждому
инструменту за весь год и сравнил ранги (n=235):

| Метрика | Значение |
|---|---|
| Spearman `rho` (годовое среднее) | **0.493** |
| Pearson `r` (годовое среднее) | 0.438 |

**Даже сглаженный карри-ранг не дотягивает до 0.5.** Иллюстрация уровней (годовые, отсортированы по Binance):

```
base        kraken   binance
SWARMS      125.9%    16.6%      ← ×7.6 разброс
CFG         108.0%   -46.8%      ← ПРОТИВОПОЛОЖНЫЙ ЗНАК
ARC          75.9%    29.7%
ZEREBRO      92.1%    12.4%
ALCH         78.8%    11.5%
...
AXS         -79.1%   -40.6%
SKL         -90.9%   -46.8%
```

CFG: на Kraken лонги платят шортам (+108%), на Binance — шорты лонгам (−47%). Позиционирование
и формула премии **специфичны для площадки**.

## Решение (критерий зафиксирован до расчёта, §4.3)

| Средняя `rho` | Решение |
|---|---|
| ≥ 0.8 | исследовать S12 на Binance |
| 0.5 – 0.8 | Binance с дисконтом |
| **< 0.5** | **forward-путь на Kraken** |

Первичная метрика (дневная) = **0.163**, все дни < 0.5. Более щедрая проверка (годовое среднее)
= **0.493**, тоже < 0.5. **Обе ниже планки → ранжирование НЕ переносится.**

**Ярлык «исследовать на Binance, торговать на Kraken» недействителен.** Это ровно та непроверенная
посылка, которую doc 34 §3.1 требовал проверить перед постройкой стенда — и она не подтвердилась.

## Следствия

- **Путь S12 — forward-накопление на Kraken** (§8). Год данных уже есть (2025-08→), ещё
  ~1–1.5 года копится, осмысленный тест ориентировочно с 2028.
- **§3.2:** публичный funding-эндпоинт Binance из ЕС доступен (235 инструментов скачаны с
  локальной машины без geo-блока) — но это теперь неважно, раз ранги не переносятся.
- **§4.4 (смещение выживаемости по перпам Binance):** не применимо — путь через Binance не принят.
- **Промежуточный ход (§8):** на имеющемся годе Kraken посчитать `IC` кросс-секционного
  funding-сигнала — покажет порядок величины, стоит ли ждать forward. Не доказательство, но ориентир.
- Платный источник истории Kraken-funding с делистнутыми — оценить только при положительном `IC`.

## Оговорки

- Дневная `rho` 0.163 занижена дневным шумом по 235 в основном микрокап-инструментам; честнее
  для карри — годовое среднее 0.493. Решение (< 0.5) держится под обеими метриками.
- Год перекрытия — единственный доступный (глубина Kraken ~1 год). Тест переносимости на более
  длинном окне невозможен, пока не накопится forward.
