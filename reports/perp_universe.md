# Вселенная перпетуалов Kraken — пригодность для S12 (doc 33 §B)

Проверено вживую 2026-08-08, Kraken Futures API.

## B1. Что выяснено

| Вопрос | Ответ |
|---|---|
| Полный список инструментов | **298 инструментов, 284 торгуемых перпа `PF_*`** (v3 `/instruments`) |
| Глубина истории funding | **~1 год**: PF_XBTUSD n=8800, **2025-08-06 … 2026-08-08** (v4 `historicalfundingrates`) |
| Интервал funding | **ЧАСОВОЙ (1h)** — timestamps 08:00/09:00/10:00… (8800/год ≈ 24/день). **НЕ 4ч**, как в doc 33 §A1 |
| Делистнутые (PF_LUNAUSD) | вернул 1 ставку — история частично есть, но глубина всё равно ~1 год |
| OHLCV / OI | доступны через charts/ticker API (не проверял глубину — funding уже биндит) |

## B2. Критерий пригодности — НЕ выполнен

| Требование §B2 | Факт | ✓/✗ |
|---|---|---|
| Состав восстановим на истор. даты (помесячно) | список инструментов есть, историч. состав — нет | частично |
| funding + OHLCV, включая ушедшие | funding частично для делистнутых | частично |
| **Глубина ≥ 3 года** | **~1 год** (v4 отдаёт только ~12 мес; v3 → 404) | **✗** |

**Вывод: вселенная перпетуалов Kraken в текущем виде для 3-летнего S12-бэктеста НЕ пригодна** — funding-история всего ~1 год. Это не смещение выживаемости (§B2 fallback про наивную вселенную здесь вторично) — это просто нехватка глубины у бесплатного эндпоинта.

## Варианты (по «что дальше §B»)

1. **Binance funding для исследования** (7 лет, 2019-09→, десятки перпов) — глубина есть, но: (а) Binance geo-заблокирован из ЕС для торговли (торгуем на Kraken); (б) свои делистнутые перпы. Для research-бэктеста S12 глубже и шире — разумный основной путь, торговля отдельно на Kraken.
2. **Forward-only на Kraken** — копить funding/OHLCV/mark с сегодня; осмысленный S12-тест ≥1.5–2 года.
3. **Платный источник** истории перп-funding с делистнутыми.

**Рекомендация:** для S12-research использовать **Binance funding** (глубина 7 лет, много перпов), измерив смещение выживаемости по делистнутым перпам Binance (§17 §3.3) — при этом торговое исполнение планировать на Kraken (часовой funding, см. пересчёт единиц `units_rebase.md`).
