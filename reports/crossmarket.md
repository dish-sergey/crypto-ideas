# Кросс-рыночная проверка §8 — rules2d vs baseline_sma200

Оба кандидата **без изменений параметров** на других рынках, тот же прокси (BULL 100% / TRANSITION 50% / прочее 0%, кэш 8%/год, реаллокация 5 дней, издержки 0.10%). Данные — Yahoo Finance (дневной OHLC). Общее окно оценки на каждый рынок = где определён rules2d (более длинный прогрев). Сравнимы относительные величины, `ratio` = ΔMaxDD/ΔCAGR к B&H (меньше = лучше).

**Вопрос:** держится ли на других рынках ничья по `ratio` (BTC: 0.15 vs 0.14) и вдвое меньшая абсолютная просадка у rules2d?

| Рынок | Период (eval) | rules2d: CAGR / MaxDD / ratio | sma200: CAGR / MaxDD / ratio | B&H MaxDD |
|---|---|---|---|---|
| BTC (референс) | 2015-05-04 … 2026-08-04 | 52.7% / -57.9% / 0.46 | 67.8% / -64.3% / — | -83.4% |
| ETH | 2018-06-26 … 2026-08-04 | 17.0% / -73.6% / 0.30 | 42.6% / -71.6% / — | -83.2% |
| S&P 500 | 1990-11-27 … 2026-08-04 | 7.4% / -21.7% / 0.06 | 8.6% / -18.0% / 0.02 | -56.8% |
| Золото | 2001-07-31 … 2026-08-04 | 10.0% / -23.7% / 0.08 | 9.9% / -23.5% / 0.08 | -44.4% |
| Нефть WTI | 2001-07-24 … 2026-08-04 | 4.4% / -41.9% / — | 3.2% / -54.9% / 0.03 | -87.4% |
| EUR/USD | 2004-10-14 … 2026-08-04 | 4.2% / -9.0% / — | 3.2% / -10.3% / — | -40.0% |

**Итог по 5 внешним рынкам:** просадку снижают оба — rules2d на 5/5, sma200 на 5/5. У rules2d **абсолютная просадка мельче, чем у sma200, на 2/5** рынков; по `ratio` rules2d лучше на 1/5.

Чтение: если ничья по `ratio` держится, но rules2d стабильно даёт меньшую абсолютную просадку на разных классах активов — это довод в пользу композита именно по глубине просадки, а не по эффективности. Если же sma200 не хуже и по абсолютной просадке — правило отсечения сложности усиливается.

**Оговорка:** на низкодрейфовых активах (EUR/USD и т.п.) плюсовой CAGR — в основном кэш 8% за время вне рынка; значимый сигнал — снижение просадки. Кэш по торговым барам слегка занижает нейтральное ядро.
