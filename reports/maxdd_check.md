# Проверка совпадения MaxDD (v3 §7.1, шаг 1)

Вопрос: MaxDD вариантов 1 (CRASH как есть) и 3 (CRASH выключен) совпадают до десятой (−25.2%). Естественно ли это (одинаковое поведение в период максимума), или артефакт?

| | Вариант 1 (CRASH как есть) | Вариант 3 (CRASH выключен) |
|---|---|---|
| MaxDD | -25.22% | -25.17% |
| Начало просадки (пик капитала) | 2024-03-04 | 2021-01-08 |
| Дно просадки | 2024-09-06 | 2021-01-27 |
| Состояние на пике | 1:BULL / 3:BULL | |
| Состояние на дне | 1:BULL / 3:TRANSITION | |

Окно просадки вар.1: 2024-03-04 … 2024-09-06 (187 дней). CRASH внутри окна: **51 дней**. Дней, где состояния вар.1 и вар.3 расходятся: **84**.

**Вывод: совпадения по существу НЕТ — это округление, бага нет.** Максимальная просадка вариантов приходится на РАЗНЫЕ события (2024-09-06 против 2021-01-27) и различается по величине (-25.22% против -25.17%); в таблице §5 оба округлились до −25.2%. Разные даты дна доказывают, что кривые капитала действительно различаются (расчёт корректен). Важно: v3 (без CRASH) даёт даже чуть меньшую просадку, чем v1 — вывод A4 усиливается, а не ослабляется.
