# S1 — полная модель P&L с базисом (doc 26 §6)

P&L_день = funding − Δбазис − издержки. Базис = (perp_close − spot_close)/spot_close (perp с fapi klines — аппроксимация close вместо mark, §6.1; spot из candles). Издержки: ребаланс дельты ∝ |ход цены| сверх 1% (задокументированная модель §6.2). Окно с базисом: 2019-09-10 … 2026-07-23 (6.9 лет).

## Влияние базиса (постоянная пара BTC)

| Модель | CAGR | MaxDD | Sharpe ± SE |
|---|---|---|---|
| только funding (как в v1) | 12.4% | -1.5% | 10.59 ± 2.88 |
| **funding − Δбазис − издержки** | **12.1%** | **-2.3%** | **6.83 ± 1.88** |

- Вклад базиса в CAGR: **-0.3 п.п./год** (funding-only 12.4% → полная 12.1%).
- Корреляция базис(вход) с Δбазис(14д): **-0.65** (гипотеза §2.2: отрицательная = неблагоприятный отбор).
- Макс. неблагоприятное дневное движение базиса: **-1.80%**.
- Sharpe после базиса = **6.83** — ВСЁ ЕЩЁ >5, искать ещё неучтённый риск (§6.1).

## Бенчмарк S4 и решение (§6.4)

S4 (стейбл-лендинг, задокументированные ставки): 2019–20 8%, 2021–22 6%, **2023–26 5%**.

**S1 (полная модель) на 2023–2026 = 7.6%/год против S4 5% → запас +2.6 п.п.**

**Запас <4 п.п. — S1 НЕ доказала, что окупает операционную сложность на актуальном подпериоде.** Не отвергается, но статус «требует пересмотра конструкции» (§6.4): вероятно работает только при высоком funding — нужен явный гейт активации по уровню ставки.

## Хвостовой риск (§6.3)

- Макс. **внутридневной** рост BTC-перп (high vs пред. close) = **+36.2%** (в v1 по дневным close было +19.5%). При 2x ликвидация ~+50%, при 3x ~+33% — **3x пробивался внутри дня**.
- В дни каскадов базис расходится сильнее всего (см. макс. неблагоприятное движение базиса выше) — именно тогда реализуется отрицательный Δбазис.

## §6.5 Ротация — пересчёт после базиса

Ротация уходит в XRP/BNB/SOL, где funding выше **из-за большего риска** (тоньше ликвидность, шире базис). Базис по альтам волатильнее, чем по BTC. Полный пересчёт ротации с индивидуальным базисом каждого альта — следующий шаг; предварительно: +4 п.п. v1 не пережили бы вычет альт-базиса и издержек альт-ротации. Решение по ротации откладывается (§6.5): принимается только если бьёт постоянную BTC И по CAGR, И по Sharpe.

**Вывод:** базис снял мнимость Sharpe 10.6 → 6.83. Оговорка: perp close вместо mark; издержки — задокументированная модель, не тиковая реальность; S4-ставки приблизительные. Для решения о деньгах хватает главного: во сколько базис и издержки обходятся и остаётся ли запас над S4.
